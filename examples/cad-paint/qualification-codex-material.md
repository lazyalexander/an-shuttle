## Interpretation

The signed-in provider was used for history verification. Missing-finish
invention used the existing deterministic API fixture; this run does not claim
live-model coverage for that separate feature. CI needs no account: it runs the
public pinned Codex binary and a local Responses fixture. The fixture rejects
credential-bearing requests and is test-only, with no production fallback.

Cancellation revokes the application's MCP capability and waits for local CLI
closure. It does not assert remote billing settlement after disconnection.
A submitted task without confirmed CLI completion is not automatically replayed.
Krita pixel comparison proves native format handling, not human visual approval
or an interactive-editing benchmark. These samples establish no latency SLO.
